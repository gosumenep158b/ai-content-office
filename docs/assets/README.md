# Aset Branding — `docs/assets`

Aset desain dan identitas visual AI Virtual Content Office. Lihat `brand-guide.md` untuk palet, tipografi, dan aturan pakai.

## Isi folder

| File | Kegunaan |
|---|---|
| `logo.svg` | Lockup horizontal (mark + wordmark) |
| `logo-mark.svg` | Mark saja (512 × 512) |
| `favicon.svg` | Favicon (64 × 64, versi sederhana dari mark) |
| `empty-tasks.svg` | Ilustrasi empty state: belum ada task |
| `empty-research.svg` | Ilustrasi empty state: belum ada riset |
| `empty-video.svg` | Ilustrasi empty state: belum ada video |
| `brand-guide.md` | Panduan brand: palet, tipografi, aturan logo, ekspor PNG |

## Catatan

- Semua aset berformat **SVG** — sumber kebenaran untuk logo dan ilustrasi. PNG diekspor dari SVG bila dibutuhkan (lihat `brand-guide.md`).
- Folder ini **tidak menyentuh** `web/`, `supabase/`, atau kode apa pun. Integrasi ke aplikasi dilakukan tim UI (lihat bagian "Integrasi ke `web/`" di `brand-guide.md`).
- Brand ini milik produk AI Virtual Content Office — bukan logo GO.
